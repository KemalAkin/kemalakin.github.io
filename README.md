# kemalakin.github.io

Source of [kemalakin.github.io](https://kemalakin.github.io/): a personal site with work,
research and notes that carry live figures, math and code.

Built with [Astro](https://astro.build), Tailwind CSS, MDX, KaTeX and Expressive Code.
Deployed to GitHub Pages by GitHub Actions on every push to `main`.

```sh
npm install
npm run dev      # http://localhost:4321
npm run build    # type check + static build into dist/
```

Content lives in `src/content/` (notes and projects, MDX) and `src/data/` (talks, publications,
teaching, YAML).
