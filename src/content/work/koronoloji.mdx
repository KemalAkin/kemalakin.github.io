A personal project started during the COVID-19 outbreak. Case numbers were collected by web scraping with
Beautiful Soup into local data sets; death and recovery rates, data fitting and visualization were done with
Python, native Excel functions and Adobe Illustrator. Daily numbers and charts were posted to social media by
automation scripts through their APIs.

The website is no longer active; the Instagram account is still there:
[@koronoloji_com](https://www.instagram.com/koronoloji_com/).
